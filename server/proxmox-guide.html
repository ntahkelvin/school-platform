Put the School Platform on your Proxmox server

Follow the steps in order. Tick each box when it's done. Grey boxes are things to type (or press Copy and paste).

0 of 0 steps done ·
Laptop = your Windows laptop Proxmox = the Proxmox web page Server = the new Ubuntu server Phone = any phone

What you need: the Proxmox computer plugged in to your router, your Windows laptop on the same Wi-Fi, the file school-platform-server.zip in your laptop's Downloads folder, and about 45 minutes.

1

Open Proxmox

Get into the Proxmox control page from your laptop.

Turn on the Proxmox computer

Proxmox computer

Press the power button. Wait 2 minutes. If it has a screen, it shows a message like:

Please use your web browser to configure this server – connect to: https://192.168.1.50:8006/

Write that address down. (Yours will have different numbers.)

No screen? Log in to your router's page and look for a device called pve, or use the address you used last time.

Open the Proxmox page on your laptop

Laptop

Open Chrome or Edge and type the address, for example https://192.168.1.50:8006

You'll see a warning “Your connection is not private”. That's normal for your own server. Click Advanced then Continue to 192.168.1.50 (unsafe).

Log in: User name root, your Proxmox password, Realm Linux PAM. If a box says “No valid subscription”, click OK.

2

Download Ubuntu into Proxmox

Ubuntu is the system the platform runs on.

Download the Ubuntu Server file

Proxmox
  1. On the left, click the little arrow next to your server name (usually pve).
  2. Click local (pve).
  3. In the middle, click ISO Images, then Download from URL.
  4. In URL, paste this, then click Query URL:
https://releases.ubuntu.com/noble/ubuntu-24.04.5-live-server-amd64.iso
  1. Click Download. Wait until it says TASK OK (about 3–10 minutes). Close that box.

If it says the file isn't found, open releases.ubuntu.com/noble in your browser, find the file ending in live-server-amd64.iso, right-click it, choose Copy link address and paste that instead.

3

Make the virtual computer

A computer inside your Proxmox computer, just for the school platform.

Click “Create VM” and fill in each tab

Proxmox

Top right, click the blue Create VM button. Then on each tab:

TabWhat to do
GeneralName: school. Click Next.
OSISO image: choose ubuntu-24.04.5-live-server-amd64.iso. Click Next.
SystemLeave as it is. Next.
DisksDisk size: 40. Next.
CPUCores: 2. Type: host. Next.
MemoryMemory: 4096. Next.
NetworkLeave as it is. Next.
ConfirmTick Start after created. Click Finish.

Make it start by itself

Proxmox

On the left, click your new VM 100 (school). Click Options, double-click Start at boot, tick it, click OK.

Now if the power goes off, the platform comes back on its own when Proxmox restarts.
4

You only do this once. Use the keyboard: arrow keys to move, Space to tick, Enter to choose.

Open the VM's screen

Proxmox

Click 100 (school) on the left, then Console. Click inside the black screen so your keyboard works there.

Check you can log in

Wait for school login:. Type kel, press Enter, type your password (you won't see it as you type, that's normal), press Enter.

You see kel@school:~$. You're in. You can close the console now; from here on you use your laptop.
5

Send the platform from your laptop

Copy the platform and your test data to the server.

Open Ubuntu (WSL) on your laptop

Laptop

Click Start, type Ubuntu, open it. This is the same black window you use for the platform.

Save your laptop's data into a file

Laptop (Ubuntu)

Copy these lines, paste them (right-click pastes), press Enter. Type your Ubuntu password if asked.

cd ~ sudo service postgresql start sudo -u postgres pg_dump school_platform | gzip > laptop-data.sql.gz cp /mnt/c/Users/*/Downloads/school-platform-server.zip . ls -lh laptop-data.sql.gz school-platform-server.zip
You see two files listed with their sizes.

Copy both files to the server

Laptop (Ubuntu)

Change 192.168.1.60 to the address you wrote down in Part 4.

scp school-platform-server.zip laptop-data.sql.gz kel@192.168.1.60:~

It asks “Are you sure you want to continue connecting?”: type yes and press Enter. Then type the server password (from Part 4).

You see both files go across, each reaching 100%.

Connect to the server

Laptop (Ubuntu)
ssh kel@192.168.1.60

Type the server password.

The line now starts with kel@school:~$. Everything you type now happens on the server.
6

Install the platform

One command does everything.

Unpack and install

Server
sudo apt install -y unzip unzip -o school-platform-server.zip -d school-platform cd school-platform sudo ./server/install.sh ~/laptop-data.sql.gz

Type your server password if asked. It shows steps 1/9 to 9/9. It takes 5–10 minutes. Don't close the window.

Want an empty platform instead of your laptop data? Use sudo ./server/install.sh (without the file). It will then ask you to make your own owner login.

Log in to Tailscale (for the free link)

Server Phone

At step 9/9 you see something like:

To authenticate, visit: https://login.tailscale.com/a/1a2b3c4d
  1. Select that link with your mouse (it copies), or type it into your phone's browser.
  2. Sign in with Google, Microsoft, Apple or GitHub (it's free). Click Connect.
  3. Back in the black window it carries on by itself.

Turn on the public link (Funnel)

Server

The first time, Tailscale may show another link that says Funnel is not enabled. Open it, click Enable, then type:

sudo tailscale funnel --bg 80
It says something like Available on the internet: https://school.tail1234.ts.net/

See your links and check everything is green

Server
school-status
You see green dots for Database, Backend, Web server and App answering, your home network link, your anywhere link and a QR code.
7

Try it

Open it everywhere.

Open it on your phone

Phone

Point your phone camera at the QR code on the screen, or type the https://school…ts.net link. Log in with owner@demo.local and ChangeMe123!.

Make it an app: iPhone: Safari Share → Add to Home Screen. Android: Chrome ⋮ → Add to Home screen.

Change the owner password (important!)

Phone or laptop

Anyone with the link can reach the login page, so the demo password must go. Logged in as owner, open Change password and pick a strong one.

Log in as other people

Laptop Phone
  1. As owner, open your school, then Logins and passwords.
  2. Find a person (a teacher, the nurse, a security officer), click Reset password. Write down the username and password it shows.
  3. Log in as them on another phone, or in a private window.

One browser = one person. Use Chrome for one, Safari for another, and private windows for more.

8

Updates from GitHub (do this once)

So new stages arrive with one command.

Link the server to your GitHub

Server
sudo /opt/school-platform/server/link-github.sh

Type your repository like yourname/school-platform. Press Enter for branch main.

If your repository is private, it shows a long line starting with ssh-ed25519 and a GitHub page address. Open that page, paste the line into Key, title it School server, leave Allow write access unticked, click Add key, then press Enter on the server.

It says Linked.

Every time there's a new stage

Laptop unzip it, run ./setup.sh, check it, then git add -A, git commit -m "…", git push as usual.

Server connect with ssh kel@192.168.1.60 and type:

sudo school-update
It backs up first, gets the new version and restarts. About 2–3 minutes.

If something goes wrong

Most problems have a quick fix.

What you seeWhat to do
Laptop can't open https://…:8006Check the laptop is on the same Wi-Fi as Proxmox. Check the address on the Proxmox screen.
scp or ssh says “Connection refused”OpenSSH wasn't ticked. In the Proxmox Console, log in and type sudo apt install -y openssh-server.
ssh says “Connection timed out”Wrong address. In the Proxmox Console type ip a and look for 192.168.x.x next to ens18.
Install stops with red writingRun the same install line again (it's safe to repeat). If it stops again, take a photo of the screen and send it to Claude.
A red dot in school-statusType the restart command it shows, for example sudo systemctl restart school-api.
Forgot the linkschool-status shows it again, with the QR code.
Need a backup nowsudo school-backup. Backups are also made every night at 2:30 am and kept 14 days.

Everyday commands on the server: school-status (is it running, links, QR) · sudo school-update (new version) · sudo school-backup (back up now).
